# Revenus+

Projet propre de gestion financière personnelle : FastAPI + PostgreSQL + HTML/CSS/JS.

Le frontend et l'API sont servis par **un seul service web**. Le déploiement Render utilise PostgreSQL séparément.

## Déploiement
1. Créer un nouveau dépôt GitHub et envoyer tous les fichiers.
2. Render → New → Blueprint.
3. Choisir le dépôt et `main`.
4. Mettre l'adresse administrateur dans `ADMIN_EMAILS`.
5. Déployer.
